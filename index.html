04 FIELD NOTES

常见问题

为什么不同网站查出来的 IP 可能不一样？

同一浏览器访问不同域名可能命中不同代理分流规则，IPv4 与 IPv6 也可能走不同路径。第三方检测站的服务器与数据源还可能存在差异；请在相同时间、相同浏览器和网络环境下对照。

DNS 结果出现多个国家，是不是一定泄漏了？

不一定。公共 DNS、Anycast、多级转发、测量节点和数据库定位差异都可能影响结果。更可靠的方法是对照代理关闭与开启时的解析器、运营商以及你的预期配置。

IP 纯净度 100 分，是否代表所有平台都安全？

不能。各评分网站使用的数据库、规则和时效不同，且不掌握平台内部审核模型。平台还可能考虑账户、设备、行为、支付和合规因素。本工具不会给出虚构的“安全百分比”。

AndyIPTest 会保存我的 IP 或指纹吗？

本站无自建后端及分析脚本，不主动持久化 IP 查询结果。公网 IP 或 IPv4/IPv6 检测由你点击后发起，第三方 API 会看到本次请求的出口 IP；外站也有各自的隐私规则。主题、收藏仅保存在本地浏览器，GitHub Pages 等托管方可能记录常规访问日志。
